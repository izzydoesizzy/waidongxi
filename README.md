## Overview

WaiDongXi (外东西) is a multimedia website designed as a resource for foreigners interested in harnessing the potential of Chinese apps by partially removing the language barrier. The site showcases popular Chinese apps -- including Taobao, JD.com, TMall, Didi, Meituan, Waimai, Baidu, Youku, Sohu TV, IQIYI, Momo, and Tantan -- with descriptions, registration walkthroughs, navigation translations, and app discovery recommendations. The site features large cinematic background images, an iPhone X device mockup carousel, and category-based app filtering.

## Features

- **App directory** showcasing 12+ popular Chinese apps across e-commerce, food delivery, video, reference, and dating categories
- **iPhone X device mockup** with Owl Carousel for app screenshot slideshows
- **Modal popups** with detailed app descriptions and download links (e.g., Taobao with 617M monthly active users)
- **Category filtering** via MixItUp for filtering apps by type (e-commerce, food, video, reference, dating)
- **Feature highlights**: Registration walkthroughs, navigation translations, new app discovery, and revenue insights
- **Full-screen hero section** with large background images and smooth wave animations
- **Typed.js text animation** for dynamic content
- **Responsive navigation** with Bootstrap collapsible navbar
- **Page preloader** for polished loading experience
- **Social media links** in the footer
- **Owl Carousel** for client/partner logo display

## Getting Started

1. **Clone the repository**
   ```bash
   git clone git@github.com:izzydoesizzy/waidongxi.git
   cd waidongxi
   ```

2. **Open in browser**
   ```bash
   open index.html
   ```
   No build step or server required -- simply open `index.html` in any modern web browser.
